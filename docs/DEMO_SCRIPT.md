# A 90-second demonstration

This is a suggested narration, not a claim that a measured run lasted 90 seconds. Keep the visible **mock** banner in the recording until live evidence exists.

1. **Opening:** “This is Ringback, a receptionist for the call a small-business owner cannot take. This recording uses a scripted model; the business, caller and phone identifier are fictional.” Show the landing page and choose Juniper Moon Salon.
2. **Caller:** Enter a fictional name and `demo-001`. Start the conversation; point out the AI and transcript notice. Ask the haircut price, then request a future weekday time. Show the assistant repeating the name, phone, service and time. Say “yes”. Without an ElevenLabs key, type; do not dub speech over the video and imply a live voice loop.
3. **Owner:** Open the protected workspace. Show the confirmed appointment, workflow ID, transcript and measured per-turn metrics. Explain that booking value is configured service value, not revenue received. Show the outbox as an SMS/email preview, not a real message delivery.
4. **Urgency:** In the plumbing console, say “I smell gas”. Show the urgent inbox record and the assistant's honest delivery wording. This is not emergency dispatch.
5. **Durability:** Open the evidence panel and the actual chaos JSON. Explain: the local worker was killed after confirmation; a restarted worker completed with one outbox confirmation. Render's ephemeral-disk limits are different.
6. **Close:** Show onboarding. Paste a fictional description, review the draft, save and test-call it. End with the live-verification button and the missing-key limitation.
